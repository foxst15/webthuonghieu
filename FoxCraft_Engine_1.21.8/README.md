# 🦊 Fox Craft V9.0 Engine - Java 1.21.8

Dự án Game Engine 3D Fox Craft được xây dựng trên Three.js, tích hợp bộ nạp khối động theo chuẩn **Minecraft Java 1.21.8**.

## 📁 Cấu trúc thư mục:
```
FoxCraft_Engine_1.21.8/
├── FoxCraftBlockLoader.js   # Module Loader Three.js động
├── package.json
├── README.md
└── assets/
    └── minecraft-1.21.8/
        └── blocks.json      # Cơ sở dữ liệu Khối 1.21.8 chuẩn
```

## 🚀 Cách chạy dự án:
1. Mở thư mục bằng VS Code.
2. Cài đặt extension **Live Server**.
3. Chạy `mc.html` với Live Server để trải nghiệm hệ thống nạp block 1.21.8 mượt mà nhất.
